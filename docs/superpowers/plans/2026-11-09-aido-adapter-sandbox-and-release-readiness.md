# AIDO Phase 7 & 8: Isolierte Adapter-Prüfbank für unbekannte Programme, Saubere Deinstallation & Release-Readiness

> **For agentic workers:** REQUIRED SUB-SKILL: Use `superpowers:subagent-driven-development` to implement this plan task-by-task using `Model: "flash"` for subagents.

**Goal:** Complete Phases 7 and 8 of the AIDO roadmap: implement the Isolated Adapter Synthesis & Verification Sandbox (`src-tauri/src/app_intelligence.rs`) for onboarding unknown Windows applications without risk, plus the Zero-Destruction Clean Uninstaller & Release Readiness Engine (`src-tauri/src/smart_installer.rs`), and integrate both into `AidoCore`, `aido-cli`, and the Desktop UI.

**Architecture:**
1. **`src-tauri/src/app_intelligence.rs` (Phase 7 — Adapter Sandbox):**
   - Adds `AdapterSandboxReport` and `synthesize_and_verify_unknown_app_adapter`: inspects an unknown program's surface in read-only/sandbox mode (`ActionKind::SynthesizeAndVerifyAdapter`), generates an `AutoGenerated` capability profile separating harmless (`Verified`) from state-modifying (`Restricted`, `requires_approval: true`) actions, persists it to `app_registry`, and returns a detailed German verification report.
2. **`src-tauri/src/smart_installer.rs` (Phase 8 — Clean Uninstaller & Release Readiness):**
   - Adds `CleanUninstallPlan` and `ReleaseReadinessReport`.
   - `prepare_clean_uninstall` & `execute_clean_uninstall` (guarded by `ActionKind::ExecuteCleanUninstall` and a one-time `ApprovalToken`) remove only AIDO-owned temporary/cache artifacts while guaranteeing that existing local AI models (`D:\AI_Models\...`) and user projects remain 100% untouched.
   - `evaluate_release_readiness` verifies all security, privacy (`PrivateOffline`), and zero-destruction gates across Phases 0–8.
3. **`src-tauri/src/lib.rs`, `src-tauri/src/main.rs`, `index.html`, `src/main.ts`:**
   - Integrates Phase 7 & 8 into `AidoCore`, adds `aido-cli release-check` and Step `[9/9]` to `aido-cli demo`, and adds the interactive **„🧩 Adapter-Sandbox & Release-Check“** view to the Desktop UI.
